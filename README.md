# Chintan Chhajed — AI & Full-Stack Engineer Portfolio

A modern, high-performance developer portfolio built with **Next.js (App Router)**, **Tailwind CSS v4**, **TypeScript**, and **Framer Motion**. Designed with an Awwwards-inspired aesthetic, featuring cursor-aware fluid interactions, dynamic spotlights, and real-world project showcases.

## 🚀 Key Features

- **Awwwards-Tier Creative Design**: Deep dark space aesthetic with violet highlights, interactive spotlight grids, and ambient blur orbs.
- **Hardware-Accelerated Fluid Cursor**: Zero-lag spring-animated cursor tracking with interactive hover states.
- **Featured Project Showcases**:
  - **Neighborhood Sustainability Hub (NHS)**: Community-driven platform for resource sharing, local food systems, and environmental metrics.
  - **Vectoria**: Advanced vector database and semantic search engine engineered for high-dimensional embeddings.
  - **AI Stock & Trader Intelligence**: Real-time sentiment analysis and predictive trading algorithms.
  - **Enhanced YOLOv8s Object Detection**: High-performance computer vision model with optimized inference pipelines.
- **Modern Tech Stack**: Next.js 16+, React 19, Tailwind CSS v4, Framer Motion, Lucide Icons.
- **Accessible & Responsive**: Fully keyboard accessible, WCAG AA compliant contrast, and optimized across mobile, tablet, and ultra-wide screens.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 💻 Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/chintan1529/MyPortfolio.git
   cd MyPortfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

To test the production build locally:

```bash
npm run build
npm run start
```
